# 特殊客人設定檔(用記事本開啟,存檔時選 UTF-8)
#
# 每一行是一位特殊客人。開頭是 # 的行是說明,遊戲會略過。
#
# 格式(欄位之間用 ： 或 | 隔開):
#   圖片編號：名字：配料(依點單順序,用 、 隔開)：金錢倍率：名聲倍率
#
# 說明:
#   圖片編號 = 這個資料夾裡的圖片檔名,例如 1 代表 1.png
#   名字     = 上菜時會顯示在頭上「★特殊客人・名字」,可以空白
#   配料     = 這位客人「固定」點的配料,順序也固定。要依序放才算「非常完美」
#              可用:葱花、海苔、溏心蛋、叉燒、筍乾、花花、玉米、炙燒五花、豆芽、辣味噌
#              同一種可以重複寫,例如:溏心蛋、溏心蛋、叉燒
#   金錢倍率 = 上菜收入乘幾倍,不寫就是 2
#   名聲倍率 = 名聲(升級用)乘幾倍,不寫就跟金錢倍率一樣
#
# 注意:
#   - 玩家還沒解鎖的配料,這位客人就不會出現。
#     例如點了叉燒,要等級 2 之後她才會來。
#   - 大約每 8 位客人會有 1 位特殊客人(只要這個資料夾有放好圖和設定)。
#   - 演示模式不會出現特殊客人。
#
# 範例(把前面的 # 拿掉就會生效,記得要有 1.png):
# 1：潔諾：海苔、溏心蛋、叉燒：2：2
# 2：老闆娘：葱花、玉米：3
