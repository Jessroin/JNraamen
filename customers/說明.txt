【客人圖片資料夾】

把你畫好的客人圖片放進這個資料夾,遊戲會自動讀取,每位客人隨機抽一張。

命名方式:
  1.png、2.png、3.png …(依序編號,最多 60 張)
  編號中間不要跳號,例如有 1、2、4 但沒有 3,第 4 張就不會被讀到。

圖片規格:
  1. 一定要 PNG、背景透明。
  2. 角色站立、正面,腳在圖片最下方。遊戲會自動切掉四周的透明空白,
     並把腳對齊座位,不用自己抓邊界。
  3. 建議用「像素原尺寸」存檔,高度約 40~50 個像素格。
     例如目前的 1.png 就是 50×50 格的圖放大 3 倍存成 150×150,
     遊戲會自動偵測並還原成原本的像素格(最大偵測到 8 倍),不會變形。
  4. 如果圖片太大(切掉空白後高度超過 70px),會自動縮到 44px 高。
  5. 沒有放任何圖片時,遊戲會用內建的預設客人。

注意:
  - 這個資料夾要和 index.html(或 jnr.html)放在同一層。
  - 上傳到 GitHub 時,整個 customers 資料夾一起上傳,
    資料夾裡每個檔案都要上傳(不能只傳壓縮包)。
  - 用電腦直接雙擊開檔案時,瀏覽器可能不讓遊戲讀取圖片內容,
    自動還原像素格的功能會失效,圖片會用原尺寸顯示。
    建議用 GitHub Pages 網址玩,或把圖片直接存成像素原尺寸。
